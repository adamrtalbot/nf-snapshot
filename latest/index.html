nf-snapshot

Check published outputs against a committed snapshot.
Get startedView on GitHub

nf-snapshot checks the files a Nextflow run publishes against a JSON snapshot committed to your pipeline repository. If a file is missing, changed, or unexpected, the run exits with status 1.

See what changed

Section titled “See what changed”

The plugin captures files the current run publishes through workflow outputs or publishDir. It decompresses .gz files before comparing them and expands published directories into their files.
